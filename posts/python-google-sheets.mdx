## Getting Started

To get started, you'll need two packages, that you can get from pip, either directly in your machine or in your virtual environment (I'll recommend the later, but hey! remember the title? so I won't blame you for going with the former).

```bash
pip3 install gspread
pip3 install oauth2client
```

Now we can truly begin by importing gspread and ServiceAccountCredentials from oauth2client. We'll also be importing Pretty Print as we're going to be handling dictionaries a lot.

```python
import gspread
from oauth2client.service_account import ServiceAccountCredentials
import pprint
```

First we'll create a scope with `https://spreadsheets.google.com/feeds` and `https://www.googleapis.com/auth/drive`, as well as the credentials using this scope as well the contents of client_creds.json. Using this credential, we'll create a client with the authorisation to access the google sheets.

```python
scope = ['https://spreadsheets.google.com/feeds', 'https://www.googleapis.com/auth/drive']
creds = ServiceAccountCredentials.from_json_keyfile_name('client_creds.json', scope)
client = gspread.authorize(creds)
```

Getting access to the worksheet then is just matter of one line. (Well, two here, but you get the gist)

```python
SHEET_NAME = 'PyGSheets' # Name of the sheet
SHEET_NO = 0 # Index of sheet, starting from 0
sheet = client.open(SHEET_NAME).get_worksheet(SHEET_NO)
```

Or you can get the worksheet by name

```python
sheet = client.open(SHEET_NAME).worksheet(NAME_OF_INDIVIDUAL_SHEET)
```

You can now use this sheet instance to do all the basic CRUD operations (put a pin in this) in that particular sheet.

## Creating new data

You can insert data into your spreadsheet in many different ways.

**1) You can insert an entire row at a time.**

```python
row = ["This", "row", "was", "inserted", "using", "python"]
index = 5 # This is the index of row, starting from 1
sheet.insert_row(row, index)
```

<Image src="/images/posts/inserting-rows.webp" alt="Inserting rows" width="800" height="400" />

**2) While there is no analogous function to insert_row for columns**, you can use `insert_rows` and `insert_cols`, which takes a 2-D list of values, and a starting index to update.

```python
column = [
    ["This", "column", "was", "inserted", "using", "python"],
    ["This", "column", "was", "also", "inserted", "using", "python"],
]
index = 5
sheet.insert_cols(column, index)
```

**3) There is also `update_cell` for granularity of a cell**, or the big daddy method `batch_update`, but we'll come back to those in a bit.

## Reading data

**1) You can get all the records in a dictionary form** by using `get_all_records`. PPrint comes real handy when dealing with the results.

```python
sheet_data = sheet.get_all_records()
pp = pprint.PrettyPrinter()
pp.pprint(sheet_data)
```

<Image src="/images/posts/read-all-values.webp" alt="Reading all values" width="800" height="400" />

**2) You can also get the values of individual rows and columns.**

```python
row = 1 # Starting from 1
col = 1 # Starting from 1
row_values = sheet.row_values(row)
col_values = sheet.col_values(col)
```

**3) Or you can drill down the granularity of a cell with**

```python
row = 1  # Starting from 1
col = 1  # Starting from 1
cell = sheet.cell(col=col, row=row)
```

This will return a cell object, that gives you the position of the cell in spreadsheet as well. If you're just after the value, you can use the `.value` attribute instead

```python
cell_value = sheet.cell(col=col, row=row).value
```

## Updating Data

**1) You can update a cell, whether pre-populated or not with `update_cell`**

```python
row = 1 # Starting from 1
col = 1 # Starting from 1
value = "Value"
sheet.update_cell(row, col, value)
```

**2) You can also update a range of cells together with `update_cells`**

```python
cell_list = sheet.range('A1:A7') # Create a range

for i, cell in enumerate(cell_list):
    cell.value = 'Value' + str(i + 1)

sheet.update_cells(cell_list) # Update cells
```

**3) Or you can use the big daddy of updating, `batch_update`**

```python
body = [
    {
        'range': 'A1:C2',
        'values': [['a', 'b', 'c'], ['e', 'f', 'g']],
    },
    {
        'range': 'A3',
        'values': [['e', 'f', 'g']]
    }
]

sheet.batch_update(body)
```

<Image src="/images/posts/batch-update-1.webp" alt="Batch update" width="800" height="400" />

With `batch_update`, you are not just limited to updating values, but giving cells formatting as well.

## Deleting data

Just as with `insert_rows` and `insert_cols` you can use `delete_rows` and `delete_columns` to remove a range of rows and columns from the sheet.

```python
start_index = 1 # Starting from 1
end_index = 1 # Starting from 1
sheet.delete_rows(start_index, end_index)
```

<Image src="/images/posts/delete-rows-1.webp" alt="Delete rows" width="800" height="400" />

## Doing fancier stuff

You are not just limited to tinkering with data with gspread. You can add new sheets, while specifying number of rows, columns and even index.

```python
SHEET_NAME = 'PyGSheets' # Name of the sheet
instance = client.open(SHEET_NAME)
NAME_OF_NEW_SHEET = 'New sheet'
no_of_rows = 100
no_of_cols = 100
index = 0  # Starting from 0
instance.add_worksheet(NAME_OF_NEW_SHEET, no_of_rows, no_of_cols, index)
```

You can also format cells with format method.

```python
sheet.format('A1:B1', {'textFormat': {'bold': True}})
```

There's so much that can be done here, but I'll leave it to you to find out the what's and how's.
